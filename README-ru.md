# kprpe_face — standalone дескриптор лиц KP-RPE ViT-B

[English](README.md) | **Русский**

Один класс `FaceRecognizer`: картинка + боксы + 5 точек всех лиц → дескрипторы 512-d.
Модель — KP-RPE ViT-B (CVLface, обучена на WebFace12M), код ужат до инференса и сверен с оригиналом бит в бит.

> **Веса — только для некоммерческих исследований.** Они не входят в репозиторий и скачиваются с Hugging Face
> авторов при первом запуске. Своей лицензии у весов нет; карточка модели просит соблюдать лицензию обучающих данных
> (WebFace260M / WebFace12M: только академические исследования, без коммерческого использования). См. «Лицензии».

## Установка
```bash
pip install git+https://github.com/rydenisbak/kprpe_face_rec.git
# или из клона: pip install .   (pip install -e . для разработки)
```
Зависимости: numpy, opencv-python, torch, safetensors.

Веса (460 МБ) скачиваются автоматически при первом `FaceRecognizer()` в кэш `~/.cache/kprpe_face/`
(закреплённая ревизия HF-репозитория, проверяются размер и sha256). Скачать заранее, например при сборке
Docker-образа:
```bash
kprpe-face-download
```
Без pip — `python -m kprpe_face.download`. Переменные окружения: `KPRPE_FACE_CACHE` — папка кэша,
`KPRPE_FACE_URL` — зеркало того же файла. Офлайн: положить файл в `kprpe_face/weights/model.safetensors` или в кэш,
либо передать путь `FaceRecognizer(weights=...)`; `download=False` запрещает скачивание.

## Использование
```python
import cv2
from kprpe_face import FaceRecognizer

rec = FaceRecognizer()                                   # устройство: cuda > mps > cpu
image = cv2.cvtColor(cv2.imread('frame.jpg'), cv2.COLOR_BGR2RGB)
descr = rec(image, bboxes, landmarks)                    # (N, 512) float32, L2-нормированы
descr, norms = rec(image, bboxes, landmarks, return_norms=True)
sim = descr @ descr.T                                    # косинусная близость
```

| вход | формат |
|---|---|
| `image` | HxWx3 uint8, RGB; для BGR — `FaceRecognizer(input_color='bgr')` |
| `landmarks` | (N, 5, 2) в пикселях этой картинки, (x, y): левый глаз, правый глаз, нос, левый угол рта, правый угол рта («левый» = слева на картинке, как в RetinaFace / InsightFace); или (N, 10) вперемешку x0, y0, x1, y1, … |
| `bboxes` | (N, 4+) x1, y1, x2, y2[, score] или `None`. Модели бокс не нужен (выравнивание только по точкам); проверяется, что лиц столько же и что точки лежат рядом со своим боксом, иначе warning (обычно это перепутанный формат) |

- Все лица одной картинки идут через сеть одним батчем (кусками по `batch_size=64`, только если лиц больше).
- `norms` — норма сырого эмбеддинга, растёт с качеством лица. Для трека удобно усреднять дескрипторы с весом = норма.
- `flip=True` — flip-TTA (сумма эмбеддингов кропа и его зеркала), примерно в 2 раза медленнее.
- Отладка: `rec.align(image, landmarks)` → кропы 112×112 RGB и точки в [0, 1];
  `rec.embed_aligned(crops, keypoints)` → сырые эмбеддинги.

## Как работает
1. Подобие (сдвиг, поворот, один масштаб) по 5 точкам на шаблон ArcFace 112×112, МНК (Umeyama);
   `cv2.warpAffine`, билинейно, за краем чёрное.
2. Те же 5 точек переносятся той же матрицей в кроп и делятся на 112 → второй вход сети.
3. RGB, (x/255 − 0.5)/0.5 → ViT-B: патчи 8×8 → 196 токенов, ширина 512, 24 блока, 16 голов, на выходе 512-d.
   Точки влияют только на внимание: смещения каждого патча до 5 точек → линейный слой → для каждого блока и головы
   таблица добавок к логитам внимания по 7×7 клеткам относительного положения соседа.
4. L2-нормировка.

## Проверка
Сверено с оригинальным кодом CVLface (ViT + KP-RPE) на закрытом наборе из 2903 реальных лиц (селфи и кадры с камер):
- все 283 тензора весов и индекс клеток RPE совпадают;
- выровненные кропы и точки совпадают бит в бит;
- при одинаковом батчинге (по 64 лица, MPS) дескрипторы совпадают бит в бит — с flip и без;
- при другом размере батча или на другом устройстве — только шум float32: максимум разницы по компоненте 2.7e-7
  (батч 1, MPS) и 1.3e-6 (CPU против MPS), 1 − cos ≤ 3e-11;
- кадр с 8 лицами одним батчем совпадает бит в бит с вызовами по одному лицу; BGR-вход и точки (N, 10) дают тот же
  результат.

## Скорость (Apple M1 Max)
- MPS: ~20 мс на вызов с одним лицом (вместе с выравниванием); батчем по 64 — ~10 мс на лицо.
- CPU: ~65 мс на лицо (батч 64).
